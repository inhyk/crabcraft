# World of Crabcraft

A browser fantasy RPG where every character is a [Jumper](https://github.com/KingKongRobotics/jumper)
crab robot. Six races, three classes, one quest chain, one rusted tyrant. Built for the Crab Robot
Open-source Challenge 2026.

```bash
pnpm install
pnpm dev        # http://localhost:5173
pnpm build      # static site in dist/
```

Design: `docs/design.md`. Requirements: `requirements/crabcraft-spec.md`. Credits: `NOTICE.md`.
