# 새벽의 섬 주민 퀘스트와 반복 보스 경험치

월드 3의 퀘스트를 기존 2개에서 12개로 늘린다. 기존 저장의 퀘스트와 레벨은 유지하며, 새 부탁은 새벽 항구 주민에게 받을 수 있다. 한국어와 영어를 지원한다.

| 부탁 | 주민 → 보상 받는 주민 | 목표 | 경험치 |
|---|---|---|---:|
| 항구의 구호 물자 | 로안 → 산호 | 항구 구호 상자 3개 | 6,000 |
| 바닷바람 약초 | 산호 | 정원의 약초 3개 | 6,500 |
| 오르막길에 등불을 | 루멘 | F를 길게 눌러 등불 3개 켜기 | 7,000 |
| 잃어버린 새벽의 지도 | 셀레네 | 정원·진주 해안·전망대 탐험 | 7,500 |
| 항구를 지켜라 | 바론 | 해안 약탈자 8마리 | 8,000 |
| 대장간을 깨울 불씨 | 플린 | 불씨 광석 3개 | 8,500 |
| 돌아올 친구를 위한 진주 | 메리 | 진주 3개 | 8,000 |
| 정찰대의 편지 | 루멘 → 로안 | 선장에게 편지 전달 | 6,500 |
| 새벽의 봉인 | 셀레네 | 성채 앞 봉인 3개 | 9,500 |
| 성채 앞 마지막 순찰 | 바론 | 황혼 파수병 12마리 | 12,000 |

수집물 18개와 탐험 장소 3곳을 배치한다. 퀘스트 추적 화살표는 남은 물품이나 장소, 완료 후 보상을 주는 주민을 가리킨다. 등불은 1.5초 동안 F를 누르며, 도중에 다른 월드로 이동하면 켜지지 않는다. 한 장소를 반복 조사해도 목표는 한 번만 진행된다. 물품·등불·퀘스트 진행은 개인별로 저장되므로 다른 모험가의 부탁을 소모하지 않는다. 미라를 보레아스에게서 구한다는 기존 이야기는 유지한다.

다섯 보스는 첫 승리와 재도전 승리 모두 코인과 경험치를 함께 지급한다. 기존 코인의 승리당 1회 수령 검사를 공유해 중복 사망 알림과 네트워크 재전송으로 보상이 늘어나지 않는다. 첫 승리 이야기·왕관·엔딩은 기존처럼 한 번만 진행된다. 별도의 퀘스트 경험치는 그대로 지급된다.

| 보스 레벨 | 코인 | 승리 경험치 |
|---:|---:|---:|
| 3 | 150 | 500 |
| 10 | 500 | 1,000 |
| 20 | 1,200 | 1,500 |
| 100 | 5,000 | 3,200 |
| 300 | 15,000 | 18,000 |

서버 변경이나 새 서버 기능은 필요하지 않다.

검증: `pnpm build`, `pnpm test:boss`, `pnpm test:engine`, 네이티브 Chrome의 `node tools/qa-dawn-requests.mjs`. 브라우저 검사는 NPC 수락과 보상, 실제 F 수집·등불, 탐험·배달, 추가 물품 접근, 저장 복구, 다섯 보스 첫/반복 경험치와 중복 수령 방지를 확인한다.
