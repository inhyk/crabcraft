# 무기·방어구 대장간

각 월드의 대장장이에게 F로 말을 걸면 전용 강화 화면을 연다. 기존 공격 강화는 무기 강화로 이어지며 기존 `attackRank` 저장을 유지한다. 방어구는 새 `armorRank`를 사용하고 이전 저장은 +0으로 시작한다. 두 장비는 각각 +100까지 강화할 수 있다.

- 무기: 단계당 기본 공격·공격 기술 배율 +8% (기존과 동일).
- 방어구: 받는 피해 배율 `1 / (1 + 0.04 × 단계)`. +25에서 피해 50% 감소, +100에서 80% 감소. 최종 타격 피해는 최소 1이다.
- 비용: 장비별 다음 단계 × 100 코인. 서로 다른 장비의 강화 비용은 독립적이다.
- 실패·장비 파괴 없이 강화하고 코인·두 강화 단계를 즉시 저장한다. 월드를 이동하거나 게임을 다시 열어도 유지한다.
- 전투 중, 사망·이야기 연출 중에는 구매할 수 없다. 코인이 부족하거나 최고 단계면 코인을 차감하지 않는다.

화면은 무기·방어구를 금색/청색 카드로 구분하고 기존 전투 그림, 현재→다음 능력치, 강화 단계 진행 막대, 필요 코인과 부족 코인을 표시한다. 강화 성공 메시지·빛·효과음을 제공하며 동작 줄이기 설정을 존중한다. 영어와 한국어를 지원하고 작은 화면에서는 내부 스크롤과 세로 카드 배치를 사용한다. Escape/닫기와 키보드 포커스 이동을 지원한다. 주민 퀘스트 버튼으로 기존 부탁을 계속 받을 수 있다.

멀티플레이는 피해를 받는 플레이어에서 방어구를 한 번 적용한다. 다른 플레이어에게 보낼 때 먼저 피해를 깎지 않으므로 호스트/게스트의 방어 효과가 섞이거나 이중 적용되지 않는다. 방어구가 피해를 줄인 다음 일시적인 보호막이 남은 피해를 흡수한다. 서버·프로토콜 변경은 필요 없다.

검증은 실제 구매/저장과 실제 Combat/BattleSync의 솔로·멀티플레이·PvP 방어 효과를 포함한다. `pnpm build`, `pnpm test:boss`, `pnpm test:multiplayer`, `node tools/qa-equipment.mjs`를 실행한다. 브라우저 검사는 기존 저장 복구, F 대장간 열기, 무기/방어구 구매·가격·잔액, 코인 부족, 이동 차단, Escape, 방어 효과, 재접속, 주민 부탁과 KO/EN·작은 화면·최고 단계를 확인한다.

구매와 강화는 별도 단계다. 처음에는 무기·방어구가 미보유로 표시되고 각각 100코인으로 +1 장비를 구매·장착한다. 구매하지 않은 장비는 강화할 수 없고, 중복 구매는 코인을 차감하지 않는다. 기존 강화 저장은 이미 보유한 장비로 복구한다. `weaponOwned`·`armorOwned`도 저장한다.

친구 대전은 멀티플레이 패널의 **⚔ 친구랑 싸우기**로 전용 방을 만들면 바로 시작한다. 방 코드나 초대 링크를 공유하고 친구가 참가하면 가까이에서 클릭/Tab으로 선택해 공격 기술을 사용한다. 같은 파티는 보호되며 방장만 협동/대전 모드를 바꾼다. 공개 월드에는 대전을 강제하지 않는다. `node tools/qa-friend-duel.mjs`는 실제 두 Chrome 세션과 방 전송으로 상호 피해·표시 체력·방어구·파티 보호·협동 복귀·공격 키를 확인한다.
