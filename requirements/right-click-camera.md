# 우클릭 카메라 조작 끊김

## 원래 제보

> 그런데 가끔 우클릭을 눌렀을 때 설정 창 같은 게 떠. 키보드가 눌려 있는 상태가 지속되면서 원활하게 움직이지 못하게 돼.
> 드래그를 그만해야지 하면서 뗐을 때 문제가 발생해.

## 확인한 내용

- 환경: Windows, Chrome.
- 발생 빈도: 가끔.
- 우클릭을 누른 채 화면을 회전하고 버튼을 떼는 과정에서 기본 우클릭 메뉴가 나타남.
- 나타나는 것은 게임 설정 창이 아닌 평소 우클릭할 때 나오는 기본 메뉴임.
- 화면 회전이 끊기고 이동 키가 계속 눌린 듯한 증상이 함께 제보됨.
- 추가 확인: 게임 화면에서 드래그를 시작해 오른쪽 퀘스트 창 위에서 버튼을 뗄 때 발생함. 채팅창은 확인된 재현 위치가 아님.
- 정확한 발생 조건과 원인은 구현 전 미검증임.

## 목표와 범위

게임 화면에서 시작한 우클릭 카메라 조작이 브라우저 기본 메뉴로 넘어가지 않도록 하고, 조작이 중단되어도 이동 키나 마우스 버튼 입력이 남지 않도록 수정함.

카메라 입력과 관련된 이동 입력 처리를 포함함. 게임 밖의 일반 UI에 대한 우클릭 동작은 유지함. 서버와 게임 규칙 변경은 포함하지 않음.

## 성공 기준

- 우클릭 드래그와 해제를 반복해도 기본 메뉴가 나타나지 않음.
- 캔버스에서 시작해 HUD 위에서 끝나는 드래그도 정상 처리함.
- 실제 오른쪽 퀘스트 창의 제목과 목표 문구 위에서 해제하는 경우를 검사함.
- 우클릭 해제 후 카메라가 계속 회전하지 않음.
- 이동 키를 누른 채 화면을 회전할 수 있고 키를 놓으면 이동이 멈춤.
- 창 포커스 이탈, 탭 숨김, 포인터 취소 시 오래된 입력을 비움.
- 좌클릭 선택, 휠 확대와 축소, 채팅 입력 동작을 유지함.

## 검증 범위

자동 QA에서 기본 메뉴 이벤트의 취소 여부, 드래그 해제와 취소 후 입력 상태, 실제 게임의 이동과 카메라 동작을 확인함. Windows Chrome 실기에서 간헐적 증상이 사라지는지는 별도 재확인이 필요함.

2026-10-18 사용자 답변으로 환경과 증상을 확인했고, 요구사항 파일 저장과 수정 진행을 승인받음. HUD 경계와 취소 경로에 대한 검사는 구현 과정에서 정한 검증 항목임.
